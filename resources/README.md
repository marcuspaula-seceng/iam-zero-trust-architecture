# Resources & References

Study notes and reference materials for IAM and Zero Trust Architecture.

## Key Standards & Frameworks

| Framework | Description | Link |
|-----------|------------|------|
| NIST SP 800-207 | Zero Trust Architecture (the definitive standard) | csrc.nist.gov |
| CISA ZT Maturity Model v2.0 | Maturity assessment framework (used in this repo) | cisa.gov |
| NIST SP 800-63B | Digital Identity Guidelines (MFA, passwords) | csrc.nist.gov |
| NIST SP 800-53 | Security & Privacy Controls | csrc.nist.gov |
| NIST 800-88 | Guidelines for Media Sanitization (device wipe) | csrc.nist.gov |
| CIS Controls v8 | Prioritized security controls | cisecurity.org |
| ISO 27001 A.9 | Access Control domain | iso.org |
| GDPR Art. 32 | Security of processing | gdpr-info.eu |
